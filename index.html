📌 Project Overview

This project demonstrates how a Node.js backend application can be containerized using Docker and connected with a PostgreSQL database. The system is designed using microservice architecture where each component runs in its own container.

🎯 Objective

  • Understand Docker containerization
  • Run multiple services using Docker Compose
  • Implement communication between containers
  • Test APIs using curl commands

📌 Project Components

  • Backend: Node.js + Express
  • Database: PostgreSQL
  • Containerization: Docker
  • Orchestration: Docker Compose
  • Networking: Bridge Network

🏗️ Architecture

The project consists of two main containers:

  • Backend Container: Handles API requests
  • Database Container: Stores user data

Both containers communicate through a Docker bridge network. The backend connects to the database using the service name "db".

🔄 Working Flow

  1. User sends request using curl or browser
  2. Request reaches Node.js backend container
  3. Backend processes request
  4. Query sent to PostgreSQL database container
  5. Database stores/retrieves data
  6. Response returned to user
